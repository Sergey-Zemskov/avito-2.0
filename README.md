# Авито — портал частных объявлений

**Курсовая работа по теме 2.** «Разработка портала частных объявлений
о продаже товаров (Авито)»

База данных — Firebird (сервер RedDatabase). Сайт — Python 3 + Flask.

---

## 1. Запуск в одну команду

### Windows

Дважды щёлкните по файлу **`start.bat`**

### Linux (РЕД ОС, CentOS, Fedora)

```bash
./start.sh
```

Больше ничего делать не нужно. Скрипт сам:

1. проверит, что установлен Python;
2. поставит нужные библиотеки;
3. проверит, работает ли сервер Firebird, и подскажет, как его поставить;
4. создаст базу данных и заполнит её демонстрационными данными;
5. откроет браузер и запустит сайт.

Через несколько секунд в браузере откроется **http://127.0.0.1:5000**

Чтобы остановить сайт — нажмите `Ctrl+C` в окне скрипта.

### Единственное, что нужно поставить заранее — сервер Firebird

**Windows:** скачайте и установите Firebird 3 с сайта
[firebirdsql.org](https://firebirdsql.org/en/firebird-3-0/) либо RedDatabase.
Служба запускается автоматически. Пароль `SYSDBA` оставьте `masterkey`.

**Linux (РЕД ОС):**

```bash
sudo dnf install -y firebird firebird-utils
sudo systemctl enable --now firebird
```

Если такого пакета нет, попробуйте `firebird-superserver`.
`start.sh` предложит выполнить эти команды сам.

## 3. Где лежит база данных

Путь определяется автоматически:

| Система | Файл базы |
|---------|-----------|
| Windows | `D:\AVITO_DB\AVITO.DB` (если диска D нет — `C:\AVITO_DB\AVITO.DB`) |
| Linux | `/var/lib/firebird/data/avito.fdb` |

Свой путь можно задать переменной окружения `AVITO_DB_PATH`:

```bash
export AVITO_DB_PATH=/var/lib/firebird/data/moya_baza.fdb
```

## 4. Что умеет сайт

* список всех объявлений с поиском по названию и фильтром по категории;
* страница объявления: фотография, цена, город, категория, продавец, описание;
* добавление, редактирование и удаление своих объявлений;
* регистрация, вход и выход;
* избранное;
* сообщения между пользователями.

Оформление простое, чёрно-белое, без внешних библиотек.

## 5. Страницы сайта

| Адрес | Что показывает |
|-------|----------------|
| `/` | список объявлений, поиск и фильтр по категории |
| `/ad/<id>` | одно объявление |
| `/add` | форма добавления объявления |
| `/edit/<id>` | форма редактирования своего объявления |
| `/delete/<id>` | удаление своего объявления |
| `/favorites` | избранные объявления |
| `/favorite/<id>` | добавить или убрать из избранного |
| `/messages` | список переписок |
| `/messages/<id пользователя>` | переписка с пользователем |
| `/login` | вход |
| `/register` | регистрация |
| `/logout` | выход |

## 7. Таблицы базы данных

| Таблица | Столбцы | Назначение |
|---------|---------|------------|
| `users` | id, login, password_hash, role | пользователи сайта |
| `categories` | id, name, description | категории объявлений |
| `ads` | id, user_id, category_id, title, description, price, city, image_url | объявления |
| `favorites` | id, user_id, ad_id | избранные объявления |
| `messages` | id, sender_id, receiver_id, ad_id, message_text, created_at | сообщения |

Связи:

```
users 1 ------< ads >------ 1 categories
users 1 ------< favorites >------ 1 ads
users 1 ------< messages >------ 1 ads
```

Внешние ключи объявлены с правилом `ON DELETE CASCADE`: вместе с
пользователем удаляются его объявления, избранное и сообщения.

Пароли хранятся не в открытом виде, а в виде хеша PBKDF2-SHA256.

## 9. Если что-то не работает

| Проблема | Что делать |
|----------|------------|
| «Нет связи с базой данных» | запустить службу Firebird (Windows: `services.msc`, Linux: `sudo systemctl start firebird`) |
| `start.sh` не запускается | дать файлу право на запуск: `chmod +x start.sh` |
| Библиотеки не ставятся | `start.py` сам создаст папку `.venv` и поставит их туда |
| Объявлений нет | выполнить `python seed.py` |
| Порт 5000 занят | изменить `WEB_PORT` в `config.py` |
| Всё сломалось, хочу заново | `python setup_all.py --reset --demo` |
